1. 世界動物日 揭開保育員「動物訓練」背後的動物福祉思維

播報稿 / 引用重點
迎接十月四日世界動物日，台北市立動物園特別分享幕後的「動物訓練」秘辛。保育員以「正向強化」取代麻醉與物理保定，讓大貓熊與紅毛猩猩能自主配合量血壓和產檢，展現了現代動物園高度尊重生命與提升動物福祉的溫馨理念。

2. 新「艋舺公園」開箱 直達龍山寺最美中軸線

播報稿 / 引用重點
萬華歷史核心的艋舺公園迎來華麗蛻變，將於十月十七日舉辦開園啟用典禮！本次改造以減法美學與空間敞開為核心，打造出直達龍山寺的最美中軸線、通透的風雨迴廊與鏡面水池，四個週末更將接力推出商圈消費券、紅包場演唱會與雲門舞集經典演出，邀市民前來開箱萬華新風景。

選錄原因：艋舺公園是萬華的核心公共空間，本次「減法美學」改造及盛大的開園系列活動（包括商圈消費券與雲門舞集演出），是台北市重大的都市地景更新與民生經濟亮點。

播報稿 / 引用重點

5. 採用新工法「螺旋內襯工法」 北投東華街2段雨水下水道即將升級 10月上旬開工

播報稿 / 引用重點
為提升都市防洪安全，北投區東華街二段的雨水下水道將於十月上旬開工升級！本次工程首度引進免開挖的「螺旋內襯工法」，不僅能將交通衝擊、空污與噪音降至最低，修復後還能大幅延長下水道使用壽命達三十至五十年，打造堅韌耐災的智慧防洪城市。

選錄原因：本篇報導介紹了台北市引進國際「螺旋內襯工法」進行地下雨水下水道升級，既展示了現代化市政防災科技，也提醒市民注意北投區十月上旬開工的相關資訊。
